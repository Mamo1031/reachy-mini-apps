# Reachy Mini 実験コントローラ

幼児(3〜4 歳)のパズル課題中に、ロボット Reachy Mini が「共感的」または「論理的」な励ましの声かけをする実験のための操作ツールです。
実験者はブラウザの画面でボタンを押すだけで、ロボットが台本どおりの発話と動作を同時に行います。

このページは**実験を行う人向け**です。開発者向けの詳細は [`experiment/README.md`](experiment/README.md) にあります。

---

## 1. できること

| 画面のボタン | ロボットの動き |
|---|---|
| イントロ(あいさつ・自己紹介・課題の誘い・本番スタート) | 順序条件(ロボット先行 / 実験者先行)に合わせた順番で、必要なボタンだけが並ぶ |
| 励まし 10 種(共感 B1〜B10 または 論理 C1〜C10) | 選んだ条件の 10 個だけが大きく表示される |
| 相づち(うん / ちがうよ / そうだね / できたね) | 子どもの発話に短く応える |
| ストップ | 発話も動作も即座に止める |
| 一時停止 / 再開 | 顔追跡と小さな仕草を止めてじっとする(ボタンは押せる) |

子どもの名前は開始時にひらがなで入力すると、「〇〇ちゃんっていうんだね」の台詞に自動で入ります。

声は**人の録音**か **VOICEVOX の合成**を選べます(設定 > 声)。初期状態は録音です。

## 2. 最初の 1 回だけ行う準備

### 2-1. ソフトの導入

フォルダごと Mac(Apple シリコン)にコピーし、**`はじめる.command` をダブルクリック**します。必要なものは初回に自動で入ります(数分)。

はじめてダブルクリックしたときに「開発元を確認できないため開けません」と出たら、**ファイルを右クリック → 開く → 開く** を 1 回だけ選びます。以後はダブルクリックで起動します。

合成の声(VOICEVOX)を使う場合だけ、追加でターミナルから次を実行します(約 1.8 GB。展開に 7-Zip を使うので [Homebrew](https://brew.sh/) が必要)。**録音の声だけで使うなら不要です。**

```bash
cd experiment
./setup_voicevox.sh
```

### 2-2. ロボットとつなぐ(有線)

**無線版のロボットには LAN 端子がありません。**ロボットの背面 USB-C に有線 LAN アダプタを挿し、Mac と 1 本のケーブルで直接つなぎます。ルーターは使いません。

- **Mac 側のアダプタはチップを選びます。** Realtek RTL8153 と ASIX AX88179**B** は macOS がそのまま認識します。古い ASIX AX88179 は macOS 15 では動きません(ロボット側の Linux はどちらでも動きます)。
- 両側に固定 IP を振ります。Mac が `192.168.100.1`、ロボットが `192.168.100.2` です。

Mac 側(初回のみ)。アダプタの名前を調べてから設定します。

```bash
networksetup -listallnetworkservices                                   # 例: AX88179B
sudo networksetup -setmanual "<アダプタ名>" 192.168.100.1 255.255.255.0
```

ロボット側は一度設定すれば以後は自動です(作り直すときだけ ssh で実行)。

```bash
ssh pollen@reachy-mini.local
sudo nmcli con add type ethernet ifname eth1 con-name wired-static ip4 192.168.100.2/24
sudo nmcli con up wired-static
```

アプリの接続先(設定 > 一般 > ロボット URL)は `http://192.168.100.2:8000` です。

**Mac の Wi-Fi はロボットの制御には使いません。**iPad で操作するときだけ必要です(iPad と Mac が同じ Wi-Fi にいること)。

> **アダプタを別の個体に替えたときは、Mac 側の固定 IP を設定し直してください。** macOS はアダプタごとに別の設定を持つので、替えると IP が空の状態から始まり、ケーブルも電源も正常なのにロボットへ届きません。上の `setmanual` をもう一度実行します。

### 2-3. 電池の予兆を出す(任意)

ロボットの稼働時間と電圧低下の表示は ssh で読みます。Mac の鍵をロボットに登録しておきます。

```bash
ssh-keygen -t ed25519 -f ~/.ssh/reachy_mini_ed25519 -N ""        # 初回のみ
ssh-copy-id -i ~/.ssh/reachy_mini_ed25519.pub pollen@192.168.100.2
```

登録しないと表示が「—」になるだけで、ほかの機能には影響しません。

## 3. 実験当日の手順

1. **ロボットの電源を入れ、Mac と LAN ケーブルでつなぐ。** ダッシュボード(Reachy Mini Control)で別のアプリが動いていたら先に止めます(ロボットの取り合いになります)。
2. **Mac をスリープさせない設定にする。** サーバーも音声も接続監視もタイマーも Mac の中で動いているので、スリープすると実験が止まります。電源につないで、システム設定 > ロック画面 の自動スリープを「しない」にします。
3. **`はじめる.command` をダブルクリックします。** 黒いウィンドウが開き、しばらくすると操作画面がブラウザで開きます。このウィンドウは実験が終わるまで閉じないでください(ここにログが出ます)。

   iPad で操作する場合は、ウィンドウに出る `http://<MacのIP>:8080` を Safari で開きます(**横向き**推奨)。Wi-Fi を切っていると表示されないので、そのときは Mac で `ipconfig getifaddr en0` を実行して調べます。

4. **開始画面**の準備チェック 7 項目がすべて ✓ になるのを待ちます(✓ が付く順番は表の並びどおりとは限りません)。

   | 項目 | 内容 |
   |---|---|
   | VOICEVOX | 音声合成エンジンの起動 |
   | ロボット接続 | デーモンに届いたか |
   | モーター | モーターを入れ、まっすぐな姿勢に戻す |
   | 音声合成 | 台詞の音声を用意(録音の整形、または合成) |
   | 音声転送 | ロボットへ送る |
   | 顔追跡設定 | 追跡の ON/OFF を反映 |
   | 音量 | ロボットの音量を読む |

   初回や声を変えた直後は「音声合成」に 1〜2 分かかります。

5. 子どもの名前(ひらがな)、ちゃん / くん、順序条件、励まし条件を選んで「準備してはじめる」。名前の下に、その名前の録音があるかどうかが出ます。
6. **操作画面**で、イントロのボタンを上から順に押します。
   - ロボット先行: A1 → A2 → A3 → A4 →(ベースライン課題中はロボットは黙っている)→ A5-1 → A5-2
   - 実験者先行: A1 → A2 → A6-1 → A6-2 → A6-3
7. 「本番開始(タイマー開始)」を押すと 8 分のカウントダウンが始まります。約 30 秒に 1 回を目安に励ましボタンを押します(前回の声かけからの経過秒が出て、30 秒を過ぎると色が変わります)。
8. **終わったら、この順番で終了します。**

   1. 「セッション終了」(記録を閉じて開始画面に戻ります)
   2. 開始画面の「ロボットを休ませる」(スリープ姿勢にしてモーターを切ります)
   3. 黒いウィンドウで `Control + C`(またはウィンドウを閉じる)

   次の子どもがいる場合は「セッション終了」だけを押して、開始画面から 5 に戻ります。
   休ませたあとは「起こす」を押すまで新しいセッションを始められません。

記録は `experiment/logs/` に、日時と名前のついた CSV と JSON で残ります(詳しくは 6 節)。

## 4. 操作画面の見方

- **ランプ「ロボット」**: 緑 = 正常、黄 = 不安定または復旧中、赤 = 切断。**赤と黄(復旧中)の間は台詞ボタンが押せなくなり**、画面上部に赤い帯が出ます。黄(不安定)の間は押せます。ケーブルや電源を直すと自動で復旧し、画面下の「ログ」に「復旧が完了しました」と出ます。
- **ランプ「サーバー」**: ブラウザと Mac の通信状態です。赤でもロボットは動いています。iPad をスリープから戻したときなど、しばらくすると緑に戻ります。
- **👀 顔検出中**: ロボットのカメラが顔を見つけているとき。一時停止中も検出は続くので点いたままになりますが、ロボットはゆっくり正面に戻って止まります。顔追跡を OFF にすると消えます。
- **🔋 稼働 1:25**: ロボットの電源を入れてからの時間です。残量そのものはロボットから読めないので、この時間と次の表示で代用しています。
  - 赤 **⚡ 電圧低下(充電してください)** = 今まさに電圧が下がっている。電池切れの前兆です。
  - 黄 **⚡ 電圧低下あり** = 起動後に一度下がったが今は戻っている。
  - **—** = 読めていない(ssh 鍵が未登録、またはロボットに届いていない)。チップにマウスを載せると理由が出ます。
- **タイマー**: 本番の残り時間。**前回の声かけ**: 最後に励ましを言ってからの秒数(相づちとイントロは数えません)。
- **再生中の表示**: 今しゃべっている台詞と進み具合。別のボタンを押すと、今のものを止めて新しい台詞に切り替わります。
- **ストップ(赤)**: 何が起きても、これを押せば止まります。キーボードの `Esc` でも同じです。画面が狭いとき(iPad の縦向きなど)は右下に赤いボタンが浮きます。
- **もう一方の条件**: 折りたたまれていて、開かないと押せません(誤操作防止)。
- **顔追跡スイッチ**: 今の状態(ON / OFF / 一時停止中)と、押したらどうなるかが並んで出ます。切り替えるとそのまま設定として保存されます。
- **ログ**: 画面下で直近の操作とエラーを確認できます。

セッションは Mac のサーバーが持っています。ブラウザを閉じても、リロードしても、セッションもタイマーも続きます。

## 5. 声

### 5-1. いまの構成

初期状態は**人の録音**です(設定 > 声 の「声の種類」で「りゅうさん(録音)」)。録音が無い台詞は**無音**になり、動作だけ再生されます。記録には「録音なし・無音」と残ります。

**いま録音が無い台詞**: A5-1、A5-2、A6-1、A6-2、A6-3(本番スタート)、C5、BC1〜BC4(相づち 4 種)。

どの台詞に録音があるかは 設定 > 声 に一覧が出ます。

### 5-2. 録音を足す

`experiment/recordings/ryu/` に、**台詞 ID のファイル名**で置くだけです。サーバーの再起動は要りません(次の準備のときに拾います)。

```
experiment/recordings/ryu/B3.m4a            ← 台詞 B3
experiment/recordings/ryu/BC1.m4a           ← 相づち「うん」
experiment/recordings/ryu/names/ゆいちゃん.m4a  ← 名前を呼ぶ台詞(A2)。開始画面で入れる名前 + 呼び方
```

- 形式は WAV、m4a(iPhone のボイスメモ)、mp3 などが使えます。
- 前後の無音の切り取りは自動です。音量の加工は 設定 > 声 の「声の張り」が 0 より大きいときだけかかります。**録音の声では 0(初期値)のままが自然に聞こえます。**
- 録音時は割れない程度の音量で、同じ部屋・同じマイク距離で録ってもらいます。
- 名前の録音は、開始画面で入力した名前と一致するものが自動で選ばれます。無い場合は開始画面に「録音がありません」と出て、その台詞だけ無音になります。

### 5-3. 合成の声に切り替える

設定 > 声 > 声の種類 で「合成(VOICEVOX)」を選び、保存します。話者・速さ・高さ・抑揚はその下で変えられます。

**保存するとその場で台詞ぶんの音声が作り直されます**(合成なら 31 件で 1〜2 分)。ロボットが未接続のときは作り直しが走らないので、**準備チェックが緑の状態で保存**してください。進み具合は開始画面の「音声合成」に出ます。

「声の張り」は、声を遠くまで届きやすくするための調整です(録音にも合成にも効きます)。上げるほど音量感は増えますが、抑揚の幅が狭くなり、近くで聞くとうるさく感じます。**録音の声では 0 のままにしています。**合成の声は録音より小さいので、合成に切り替えたときだけ上げてください。

## 6. 記録(ログ)

`experiment/logs/` に、セッションごとに 2 つのファイルが残ります。

- `20260914_195610_ゆいちゃん.csv` — 起きたことが 1 行ずつ。押したボタンだけでなく、接続の変化、復旧、電圧低下、フェーズの切り替え、中断と再開、エラーも同じ形式で入ります(`kind` 列で区別)。Excel でそのまま開けます。
- 同名の `.json` — 開始した時点の条件・設定・台本の写しです。途中で設定を変えても書き直されません。

同じフォルダに `.current_session.json` という隠しファイルが作られます。サーバーが落ちたときの再開に使うもので、セッションを正常に終了すると消えます。

## 7. 困ったとき

| 症状 | 対処 |
|---|---|
| チェックリストの「ロボット接続」が待機のまま | 電源とケーブルを確認。**アダプタを替えた直後なら Mac 側の固定 IP が外れています**(2-2 の `setmanual` を再実行)。それでもだめなら 設定 > 一般 > ロボット URL を確認 |
| ランプが赤になった | そのまま待つと自動で復旧します。復旧中はボタンが押せません。復旧しない場合は電源・ケーブル |
| サーバー(黒いウィンドウ)が落ちた・閉じてしまった | `はじめる.command` をもう一度ダブルクリックする。開始画面に「前回のセッションが途中で終わっています」と出るので「続きから再開」を押す(同じ記録ファイルに続きが書かれ、本番のタイマーも中断前から続きます)。30 分以上たつと候補に出ません。「破棄」を選んでも記録ファイルは残ります |
| 声が小さい | 設定 > 動作 の一番下「ロボットの音量」で上げる(テスト音が鳴るので子どもがいないときに)。それでも足りなければ 設定 > 声 の「声の張り」を上げる(上げすぎると抑揚が平たくなり、近くではうるさくなります) |
| 声が出ない台詞がある | その台詞の録音がありません(5-1)。設定 > 声 の一覧で確認できます |
| 声と動きのタイミングが合わない | 設定 > 動作 > 音声の先行(ms)を少しずつ変える |
| 動きが速すぎる / 大きすぎる | 設定 > 動作 > ゆっくりさ(時間の倍率)と動きの大きさ |
| ロボットが子どもの方を向かない | 設定 > 動作 > 顔追跡が ON か確認。操作画面のスイッチでも切り替えられます |
| 「休止中」と出て押せない | 「起こす」を押す(音を鳴らさずにまっすぐな姿勢に戻ります)。休止中は画面が覆われ、ほかのボタンは押せません |
| 🔋 が「—」のまま | ssh 鍵が未登録(2-3)。チップにマウスを載せると理由が出ます |
| 「準備してはじめる」でエラーが出る | 音声の準備に失敗しています。ロボットが接続されているか、VOICEVOX が動いているかを確認して、もう一度 |
| 試聴や音量変更が「再生中は…」と断られる | 何か鳴っている間はできません。「ストップ」を押してから |
| 頭が動かず、アンテナだけ動く | 設定 > 動作 の追跡の方式が「ロボット内蔵」のときに起きることがあります。「ストップ」で戻ります |

## 8. 設定画面で変えられること

| タブ | 項目 |
|---|---|
| 一般 | ロボットの名前(初期値: ミミ)、実験者の呼び名、ロボットの接続先、本番の長さ、声かけ目安の間隔、電池の予兆(稼働時間・低電圧)の設定 |
| 位置 | お手本・写真カード・ピースがロボットから見てどの方向にあるか(「指さし」の向き)。「テスト」で実機確認。**保存してからテスト**してください |
| 声 | 声の種類(録音 / 合成)、録音の有無の一覧、話者・速さ・高さ・抑揚、声の張り、試聴(ブラウザ / ロボット)、名前の読み方の登録 |
| 台本 | 全部の台詞の文言と、それぞれに付ける動作。「ロボットで再生」で確認 |
| 動作 | 顔追跡(方式と速さ)、待機中の小さな仕草、ゆっくりさと動きの大きさ、可動範囲の上限、音声と動作のずれ補正、ロボットの音量 |

保存した内容はファイルに残り、次回起動時もそのまま使われます。設定画面を「操作画面へ戻る」で抜けると、保存していない変更は捨てられます。

## 9. 使いやすさと安全のために気を配っている点

**接続が切れても実験を止めない**
- 1 秒ごとにロボットの状態を確認し、ランプで常に見えるようにしている。
- 切断から復帰したら、モーターを入れ直す → まっすぐな姿勢に戻す → 音声を送り直す → 顔追跡の設定を戻す、を自動で行う(ロボットが再起動して音声が消えていても復元する)。
- サーバーが落ちても、次に起動したときに同じ記録ファイル・同じタイマーで続きから再開できる。
- ブラウザ側も、通信が途切れたら「サーバー」ランプを赤にして自動で再接続する。iPad を一度スリープしても、戻ったときに最新の状態を取り直す。
- ロボットへの動作指令は応答を待たない専用の経路(WebSocket)で送り、通信の揺らぎで動きが途切れにくくしている。

**押した瞬間に声と動きが出る**
- 台詞の音声は起動時にすべて用意してロボットへ送っておく。ボタンを押してからの待ち時間はない(名前入りの台詞だけは「準備してはじめる」のときに用意する)。
- 録音は前後の無音を自動で切り詰めるので、押してすぐ声が出る。
- 音声と動作のずれは「音声の先行(ms)」で耳に合わせて調整できる。

**子どもへの配慮**
- 起動や復旧のときに、ロボット本来の起動音を鳴らさない(黙ってまっすぐな姿勢に戻る)。
- 動きの速さと大きさは設定で落とせる(初期値は定義どおりより 1.5 倍の時間をかけ、振れ幅を 85% にしている)。動き出し・止まり際はなめらかに補間し、急に動かない。
- 顔追跡は首だけでなく腰も使い、ゆっくり向く。顔を見失っても 1.5 秒はそのままで、そのあとゆっくり正面に戻る。
- 台詞の動作は「いま子どもを見ている方向」に重ねて再生され、終わってもその方向を向いたままになる(話しかけたあとに顔をそむけない)。「ストップ」も同じ方向に戻る。指さしだけは机の絶対方向を向く。
- カメラの映像は Mac に送られず、保存もされない。ロボットから受け取るのは顔の位置の数値だけで、向きの計算を Mac が行っている。顔追跡は設定で OFF にもできる。
- 動きの大きさに上限を設けている(首の向き、腰の回転、アンテナ)。

**実験者の誤操作を防ぐ**
- 選んだ条件の台詞だけを大きく表示し、もう一方は折りたたんで隠す。
- 同じボタンの二度押しは 0.5 秒間無視する。ボタンは指で押せる大きさにしている。
- 「セッション終了」「ロボットを休ませる」「音量変更(テスト音が鳴る)」は確認してから実行する。
- 台詞・名前・位置・声・動きの速さなど変わりうるものは、コードを触らずに設定画面で変えられる。

**記録が残る**
- 押したボタン・時刻・台詞・動作・結果を 1 行ずつ即座にファイルへ書く(途中で PC が落ちても、それまでの記録は残る)。
- セッションごとに、そのとき使っていた設定と台本の写しを JSON で保存する。

**ネットに依存しない**
- 音声合成も含めてすべて Mac の中で動く。実験室にインターネットが無くても使える。

## 10. クレジット・利用条件

- **合成の声を使った場合**: [VOICEVOX](https://voicevox.hiroshiba.jp/) のクレジット表記が必要です。論文や発表では「VOICEVOX:ずんだもん」のように使用キャラクターを明記してください(キャラクターごとの規約があります)。設定 > 声 に表記すべき文字列が出ます。
- **録音の声を使った場合**: VOICEVOX のクレジットは不要です。録音した方の扱いは研究の規程に従ってください。
