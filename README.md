# Reachy Mini 実験コントローラ

幼児(3〜4 歳)のパズル課題中に、ロボット Reachy Mini が「共感的」または「論理的」な励ましの声かけをする実験のための操作ツールです。
実験者はブラウザの画面でボタンを押すだけで、ロボットが台本どおりの発話と動作を同時に行います。

このページは**実験を行う人向け**です。開発者向けの詳細は [`experiment/README.md`](experiment/README.md) にあります。

---

## 1. できること

| 画面のボタン | ロボットの動き |
|---|---|
| イントロ(あいさつ・自己紹介・課題の誘い・本番スタート) | 順序条件(ロボット先行 / 実験者先行)に合わせた順番で、必要なボタンだけが並ぶ |
| 励まし 10 種(共感 B1〜B10 または 論理 C1〜C10) | 選んだ条件の 10 個だけが大きく表示される |
| 相づち(うん / ちがうよ / そうだね / できたね) | 子どもの発話に短く応える |
| ストップ | 発話も動作も即座に止めて、まっすぐな姿勢に戻る |
| 一時停止 / 再開 | 顔追跡と小さな仕草を止めてじっとする(ボタンは押せる) |

子どもの名前は開始時にひらがなで入力すると、「〇〇ちゃんっていうんだね！」の台詞に自動で入ります。

---

## 2. 最初の 1 回だけ行う準備

Mac(Apple Silicon)で、ターミナルを開いて次を実行します。

```bash
cd experiment
./setup_voicevox.sh      # 声を作るエンジン(VOICEVOX、約 1.8 GB)を取得
uv sync --all-groups     # 必要なライブラリを入れる
```

`uv` が無い場合は https://docs.astral.sh/uv/ の手順で入れてください。

---

## 3. 実験当日の手順

1. **ロボットの電源を入れ、LAN ケーブルで Mac と同じネットワークにつなぐ**(無線は使わない)。
2. ターミナルで起動する。

   ```bash
   cd experiment
   ./run.sh
   ```

   画面に `操作画面: http://localhost:8080` と出るので、ブラウザで開く。iPad で操作する場合は、同じ行に出る `http://<MacのIP>:8080` を iPad の Safari で開く。
3. **開始画面**のチェックリスト(VOICEVOX → ロボット接続 → モーター → 音声の準備 → …)が順に緑になるのを待つ。1〜2 分かかることがある(初回は音声を作るため少し長い)。
4. 子どもの名前(ひらがな)、ちゃん / くん、順序条件、励まし条件を選んで「準備してはじめる」を押す。名前入りの音声ができると操作画面に切り替わる。
5. **操作画面**で、イントロのボタンを上から順に押す。
   - ロボット先行: A1 → A2 → A3 → A4 →(ベースライン課題中はロボットは黙っている)→ A5-1 → A5-2
   - 実験者先行: A1 → A2 → A6-1 → A6-2 → A6-3
6. 「本番開始」を押すと 8 分のカウントダウンが始まる。約 30 秒に 1 回を目安に励ましボタンを押す(前回の声かけからの経過秒が表示され、30 秒を過ぎると色が変わる)。
7. 終わったら「セッション終了」。次の子どもがいる場合は開始画面に戻って 4 から。全部終わったら「ロボットを休ませる」を押してからターミナルで `Ctrl+C`。

記録は `experiment/logs/` に、日時と名前のついた CSV(押したボタンと時刻)と JSON(条件と設定)として残ります。

---

## 4. 操作画面の見方

- **ランプ「ロボット」「サーバー」**: 緑なら正常。赤になったら理由が横に出る。ケーブルや電源を確認すると自動で復旧し、復旧時に「復旧しました」と表示される。
- **👀 顔検出中**: ロボットのカメラが子どもの顔を見つけて視線を向けているとき。
- **タイマー**: 本番の残り時間。**前回の声かけ**: 最後に励ましを言ってからの秒数。
- **再生中の表示**: 今しゃべっている台詞と進み具合。別のボタンを押すと、今のものを止めて新しい台詞に切り替わる。
- **ストップ(赤)**: 何が起きても、これを押せば止まる。
- **もう一方の条件**: 折りたたまれていて、開かないと押せない(誤操作防止)。
- **ログ**: 画面下で直近の操作とエラーを確認できる。

## 5. 困ったとき

| 症状 | 対処 |
|---|---|
| チェックリストの「ロボット」がずっと待機 | 電源と LAN ケーブルを確認。それでもだめなら 設定 > 一般 > ロボット URL に IP アドレス(例 `http://192.168.1.83:8000`)を入れて保存 |
| ランプが赤になった | そのまま待つと自動で復旧する。復旧しない場合は電源・ケーブルを確認 |
| ロボットの声が聞こえない | 設定 > 動作 > 音量 で上げる(テスト音が鳴るので子どもがいないときに) |
| 声と動きのタイミングが合わない | 設定 > 動作 > 音声先行(ms)を少しずつ変える |
| ボタンを押しても頭が動かず、アンテナだけ動く | 「ストップ」を 1 回押すと直る |
| 「休止中」と出て押せない | 「起こす」を押す(音を鳴らさずにまっすぐな姿勢に戻る) |
| 台詞や名前を変えたい | 設定画面で変更して保存。音声は次に押したときに自動で作り直される |

ダッシュボード(Reachy Mini Control)で別のアプリを動かしていると取り合いになるので、先に止めてください。

## 6. 設定画面で変えられること

| タブ | 項目 |
|---|---|
| 一般 | ロボットの名前(初期値: ドラちゃん)、実験者の呼び名(はるかお姉さん)、ロボットの接続先、本番の長さ、声かけ目安の間隔 |
| 位置 | お手本・写真カード・ピースがロボットから見てどの方向にあるか(「指さし」の向き)。「テスト」で実機確認 |
| 声 | 話者(VOICEVOX のキャラクター)、速さ・高さ・抑揚、試聴(ブラウザ / ロボット)、名前の読み方の登録 |
| 台本 | 全部の台詞の文言と、それぞれに付ける動作。「ロボットで再生」で確認 |
| 動作 | 顔追跡の ON/OFF、待機中の小さな仕草、動きの大きさの上限、音声と動作のずれ補正、音量 |

保存した内容はファイルに残り、次回起動時もそのまま使われます。

## 7. 使いやすさと安全のために気を配っている点

**接続が切れても実験を止めない**
- 1 秒ごとにロボットの状態を確認し、ランプで常に見えるようにしている。
- 切断から復帰したら、モーターを入れ直す → まっすぐな姿勢に戻す → 音声を送り直す → 顔追跡の設定を戻す、を自動で行う(ロボットが再起動して音声が消えていても復元する)。
- ロボットの名前解決(`reachy-mini.local`)が不安定でも困らないよう、IP アドレスを直接指定できる。
- ブラウザ側も、サーバーとの通信が途切れたら「サーバー」ランプを赤にして自動で再接続する。iPad を一度スリープしても、戻ったときに最新の状態を取り直す。

**押した瞬間に声と動きが出る**
- 台詞の音声は起動時にすべて作ってロボットへ送っておく。ボタンを押してから合成する待ち時間はない(名前入りの台詞だけは「準備してはじめる」のときに作る)。
- 音声と動作のずれは「音声先行(ms)」で耳に合わせて調整できる。

**子どもへの配慮**
- 起動や復旧のときに、ロボット本来の起動音を鳴らさない(黙ってまっすぐな姿勢に戻る)。
- 動きの大きさに上限を設け、公式のモーション集と同じ範囲に収めている。動き出し・止まり際はなめらかに補間し、急に動かない。
- 「ストップ」は音と動作を止めるだけでなく、必ずまっすぐな姿勢に戻す。
- 顔追跡はロボットの中だけで処理され、映像は Mac に送られず保存もされない。設定で OFF にもできる。
- 声は明るく優しいキャラクター音声(VOICEVOX)で、話す速さを幼児向けにややゆっくりにしている。

**実験者の誤操作を防ぐ**
- 選んだ条件の台詞だけを大きく表示し、もう一方は折りたたんで隠す。
- 同じボタンの二度押しは 0.5 秒間無視する。ボタンは指で押せる大きさにしている。
- 「セッション終了」「ロボットを休ませる」「音量変更(テスト音が鳴る)」は確認してから実行する。
- 台詞・名前・位置・声など変わりうるものは、コードを触らずに設定画面で変えられる。

**記録が残る**
- 押したボタン・時刻・台詞・動作・結果を 1 行ずつ即座にファイルへ書く(途中で PC が落ちても、それまでの記録は残る)。
- セッションごとに、そのとき使っていた設定と台本の写しを JSON で保存する(後から「この子のときはどの声・どの文言だったか」が分かる)。

**ネットに依存しない**
- 音声合成も含めてすべて Mac の中で動く。実験室にインターネットが無くても使える。
